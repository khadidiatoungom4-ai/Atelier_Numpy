# Objectif 
Une entreprise dispose de plusieurs capteurs installés dans différents bâtiments. Les capteurs 
mesurent régulièrement la température, l'humidité, la pression et la consommation énergétique. 
Les données doivent être préparées et analysées avant d'être transmises à un futur système de 
Machine Learning permettant de détecter des situations anormales
# Thématiques abordées 
Création de tableaux Numpy, Indexation et slicing, Filtrage booléen,  Manipulation des dimensions, Concaténation, Calcul scientifique,Broadcasting
